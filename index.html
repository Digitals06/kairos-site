The temple identity

Marble and basalt themes — or follow the OS. A frameless window with engraved controls, carved scrollbars, surfaces that scale with the window, and charts that re-palette on the flip.

evxl-accurate ranks, computed locally

Reverse-engineered from evxl.app: Voltaic energy, harmonic / top-N / count-based methods and more. Every family computes from your scores — no server fallback remains.

What to grind next

Each benchmark page names the cheapest per-scenario scores for the next tier — probed against the local engine, exact for every method family, and capped at each scenario's ladder top. When no single scenario can carry you, you get a numbered plan.

Grind coach

Pick a family and the coach watches your session: the next 3 scenarios to grind, refreshed as you play. App-side only — no game overlay, no auto-refresh race.

Weekly plaque

Plays per day, scored minutes (actual alive-time — never guessed), streak, rank changes, and your place on the Twelve-Steps frieze. One plaque, top of the app.

Scenario analytics

Every scenario of a benchmark on one screen: mini score-history charts, PB progression, spread, plateau tags and 30-day improvement. Built for screenshots.

Capture

One button composes the analytics report into a single image and copies it to your clipboard — ready for Discord or your notes.

One card per family

The stoa groups benchmarks by family: best rank seal, difficulty count, and an unroll showing every difficulty's tier-ladder rungs with grind chips — ▶ runs to next tier, or complete.

Per-scenario detail

Score history with PB progression — local plays and sync snapshots, deduplicated. Running high, 7-day average, 30-day improvement — and a sort that cycles weakest → strongest → order.

Consistency & plateau detection

Every grind target carries spread — how steady your recent runs are — plus plateau tags, so you can swap a stalled grind for one that's still climbing.

Live local plays

A background watcher reads KovaaK's Stats folder while the app is open — new sessions land in your charts on their own. No refresh click.

Rank-change toasts

Every sync diffs your two newest snapshots per benchmark. Rank moves? A RANK UP toast with old → new tier — or one summary when several shift.

Full benchmark coverage

Every benchmark tracked on evxl.app — Voltaic, Revosect, PureG, Aimerz+ and the rest — with official rank names and colors.

Search, filters & favorites

Twelve type tabs mirroring evxl's own grouping, name search, and pins that survive restarts. The registry updater keeps new seasons coming without a rebuild.

Private by design

No accounts, no telemetry — only public APIs. Everything lives in %LOCALAPPDATA%\kairos\store.db, with one-click JSON + CSV backup.

How it works — ὁδός

Three public sources in, one local file out.Nothing is uploaded anywhere. Ever.

I — SCORES

KovaaK's public score server

Scores, ranks and leaderboard positions. No login needed — only public endpoints.

II — DEFINITIONS

evxl.app lookup + registry

Finds your profile plus benchmark and rank definitions, cached with a version stamp.

III — LOCAL TRUTH

Your Stats folder

*.csv local play history, watched live while the app runs. Refresh Local re-scans without touching the network.

Everything lands in one file: %LOCALAPPDATA%\kairos\store.db — back it up, move it, it's yours.

Get Kairos — λῆψις

Running in under a minute.Windows 10/11 · free · MIT licensed

↓ Get kairos.exe — latest release
  1. Download kairos.exe from the latest release and double-click it.
  2. Enter your Steam ID (or vanity name / profile link).
  3. Hit Sync Now — your benchmarks roll in, ranks computed locally. Pick marble or basalt, then go grind.
Build from source 
# needs: git · rust · node 24
git clone https://github.com/Digitals06/kairos.git
cd kairos\crates\kovaaks-tauri\ui
npm install && npm run build
cd ..\src-tauri
cargo build --release --features custom-protocol

Full steps in the README. If Kairos helps your grind, support it on Ko-fi.
